# WalletService

REST API электронного кошелька. Позволяет регистрироваться, входить в аккаунт, управлять балансом и переводить средства другим пользователям.

## Возможности

- Регистрация с хешированием паролей BCrypt.
- Авторизация через JWT со сроком действия 15 минут.
- Один кошелёк на пользователя.
- Пополнение, снятие и переводы между кошельками одной валюты.
- История операций с суммой и остатком после операции.
- Защита чужих кошельков от просмотра и изменения.
- Транзакции и блокировки кошельков при изменении баланса.
- Валидация запросов и централизованная обработка ошибок.

## Стек

Java 21, Spring Boot, Spring Security, Spring Data JPA, PostgreSQL, Flyway, Maven, Lombok, JUnit 5, Mockito.

Код разделён на контроллеры, сервисы, репозитории, сущности и DTO. Структура базы управляется миграциями Flyway.

## Запуск

Необходимы **JDK 21** и **Docker**. Команды выполняются в каталоге проекта через PowerShell.

Запустить PostgreSQL:

```powershell
docker compose up -d
```

Сгенерировать ключ JWT и установить переменную окружения:

```powershell
$jwtBytes = New-Object byte[] 32
$jwtRandom = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$jwtRandom.GetBytes($jwtBytes)
$jwtRandom.Dispose()
$env:JWT_SECRET = [Convert]::ToBase64String($jwtBytes)
```

Запустить приложение в том же терминале:

```powershell
.\mvnw.cmd spring-boot:run
```

При запуске из IntelliJ IDEA нужно отдельно задать `JWT_SECRET` в Environment variables конфигурации запуска. Ключ хранится в формате Base64 и не должен попадать в репозиторий.

Приложение доступно на `http://localhost:8080`. Проверка запуска — `GET /api/ping`.

По умолчанию используется локальная база из `compose.yaml` на порту `5433`. Подключение можно переопределить переменными `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`. Миграции выполняются автоматически.

## API

| Метод | Адрес | Назначение |
|---|---|---|
| POST | `/api/users` | Регистрация |
| POST | `/api/users/login` | Вход и получение JWT |
| POST | `/api/wallets` | Создание кошелька |
| GET | `/api/wallets/{walletId}` | Просмотр кошелька |
| GET | `/api/wallets/user/{userId}` | Поиск своего кошелька |
| POST | `/api/wallets/{walletId}/deposit` | Пополнение |
| POST | `/api/wallets/{walletId}/withdraw` | Снятие |
| GET | `/api/wallets/{walletId}/transactions` | История операций |
| POST | `/api/transfers` | Перевод |

Регистрация и вход доступны без токена. Для операций с кошельками требуется:

```http
Authorization: Bearer <accessToken>
```

Примеры запросов находятся в `requests.http`. Их можно выполнять через IntelliJ HTTP Client. Полный сценарий создаёт тестового пользователя и изменяет данные локальной базы.

## Тестирование

Запуск тестов сервисов без базы данных:

```powershell
.\mvnw.cmd "-Dtest=UserServiceTest,WalletServiceTest,TransferServiceTest" test
```

Тесты проверяют вход, снятие средств, отказ при недостатке денег, остановку операции при запрете доступа и успешный перевод. Зависимости подменяются Mockito; реальные блокировки базы и HTTP-безопасность этими тестами не проверяются.

## Статус проекта

Учебная серверная часть без пользовательского интерфейса и подключения платёжной системы. Пополнение моделирует изменение баланса. Обновление и отзыв JWT, пагинация истории и интеграционные тесты пока не реализованы. Некоторые некорректные адреса и параметры могут возвращать `500`.
